QUY TẮC CỦA MỘT NGÔN NGỮ — Code Universe
=========================================
Cập nhật 2026-10-08. Mẫu chuẩn là JavaScript (đã làm xong, mọi ngôn ngữ khác
làm theo). Dữ liệu: server/data.db -> npm run export-data -> public/data.json.
Trang: https://t-root.github.io/code-universe/ (push lên main là tự deploy).


1. KHUNG MỤC CẤP 1
------------------
Mỗi ngôn ngữ chỉ có những mục NÓ THỰC SỰ CÓ (mục rỗng bị bỏ, thêm lại bằng
admin khi có nội dung). Thứ tự chuẩn (tên có đuôi: "Function (Go)"):

  Fundamentals      kiến thức của chính ngôn ngữ (xem mục 2). Luôn có.
  Runtime           code chạy thế nào: interpreter / compiler, VM, GC, event
                    loop, FFI; runtime thay thế (Node.js, Deno, Bun, JVM...)
  Module            CHỈ các module có sẵn của ngôn ngữ (Math, Date, JSON...);
                    hàm / lớp là con của module. Không có "Standard library"
  Package manager   công cụ (npm, pip, cargo...), lệnh cài / chạy script, và
                    tệp khai báo (package.json, Cargo.toml, go.mod), semver,
                    lockfile, workspace, xuất bản
  Library           thư viện / gói bên thứ ba (Lodash, nanoid, NumPy, serde...)
  Framework         framework (React, Express, Django...)
  Testing           framework test, assertion, mock, coverage, E2E
  Tooling           debug, profiling, lint, formatter, build, IDE / LSP
  Best practices    style guide, đặt tên, idiom, design pattern, hiệu năng,
                    bảo mật

- Chuỗi tăng dần: Module (của ngôn ngữ) -> Library -> Framework. Gói nhỏ
  (nanoid, ky, serde...) cũng là Library, không có mục Package riêng trong
  từng ngôn ngữ. "Package" chỉ là 1 note chung (root, không thuộc ngôn ngữ nào)
  giải thích khái niệm gói và liên quan tới Module, npm, pip và vài package
  tiêu biểu (Lodash, requests, Serde...).
- Dựng / chỉnh lại các mục: node server/shape-languages.mjs (bỏ mục rỗng,
  xếp đúng thứ tự).
- Library / Framework / công cụ bên thứ ba là NODE GỐC (parent rỗng, có
  language); mục chỉ liệt kê chúng qua liên kết, hiện như con. Công cụ chính
  thức đi kèm ngôn ngữ (go test, pip...) là node thường trong cây.
- HTML / CSS / SQL KHÔNG phải ngôn ngữ lập trình: HTML, CSS thuộc category
  Web, SQL thuộc Database. Vẫn có khung riêng (nhận theo tiêu đề trong
  export.mjs, api.js, admin, check.mjs):
    SQL:  Getting started, Queries, Data type, Function, Data & schema
          changes, Transactions, Index & performance, Security, Database
          systems, Tooling.
    HTML: Getting started, Syntax, Tags, Form, Media, Accessibility,
          SEO & meta, Tooling.
    CSS:  Getting started, Syntax & selectors, Box model, Layout,
          Typography & effects, Responsive, Animation, Architecture,
          Framework, Tooling.


2. FUNDAMENTALS
---------------
Getting started, Syntax, Variable, Data type, Control flow, Function, mục bộ
nhớ (pointers / ownership) nếu ngôn ngữ có, OOP, Error handling, Async &
concurrency, Import system, và mục riêng nếu cần (JavaScript: Browser).

- Variable: Basic variables (let / const / var, khai báo, đặt tên, hoán đổi)
  và Advanced variables (scope, hoisting, shadowing, closure, global).
- Data type: con là KIỂU (Basic types, String, List / Array, Map / Dict,
  Set, Option, enum...). Method là node con của kiểu; không có node
  "X methods" đứng riêng. Mỗi kiểu chính >= 3 method.
- Control flow: Condition và Loop; mỗi biến thể một node.
- Import system: cách ngôn ngữ chia code thành tệp (import / export,
  namespace, header file...). Kiến thức import / export nằm ở ĐÂY, không ở
  Module. Module + import + export của cùng một thứ gộp một node.


3. QUY TẮC TÁCH NODE
--------------------
- Một node = MỘT thứ (một hàm, một kiểu, một từ khóa, một khái niệm). Hai
  thứ khác nhau không gộp dù cùng họ: Map và Set là hai node; null và
  undefined; el.style và el.classList; Date và Temporal.
- Chỉ gộp khi KHÔNG hiểu được cái này nếu thiếu cái kia (if / else, get /
  set, extends / super, function* / yield, async / await, hoisting / TDZ).
- Thư mục (item) cũng đơn nghĩa: "Sorting arrays", không "Sorting slicing &
  joining arrays". Chỉ tạo thư mục khi đó là phân loại thật (như MDN chia),
  không gom chỉ để giảm số con. Không giới hạn số con.
- Trùng ý thì gộp một node (Promise, async/await, Module + import/export).
- Không để node gốc / liên quan trùng với chuỗi cha của chính nó.
- Tên: method có tiền tố người nhận (arr.map(), s.split()); hàm tĩnh giữ tên
  lớp (Object.keys()); thuộc tính HTML dạng a[href]. Trùng tên giữa ngôn
  ngữ thì thêm đuôi: "Loop (Go)". Tiêu đề tiếng Anh, duy nhất toàn DB (không
  phân biệt hoa thường), không dấu phẩy; tên tiếng Việt và tên ngắn làm
  alias. Chỉ dùng ký tự có trong font Square-VN (không emoji, không tab).
- Từ khóa chung (Method, Function, for, while, Class, List...) có node gốc
  TRUNG LẬP, không gắn ngôn ngữ, giải thích chung và liên kết tới node từng
  ngôn ngữ; node riêng của ngôn ngữ có đuôi (Method (Java)). Thêm từ chung:
  sửa HUBS trong server/add-generic-hubs.mjs rồi chạy lại.


4. CATEGORY VÀ KIND (hai trục)
------------------------------
- category = node thuộc lớp / lĩnh vực nào (màu, cỡ chữ, nhãn):
  Language, Module, Library, Framework, Web, Database, Tooling, Runtime,
  Testing, AI, Concept (11). Không có Mobile (Android, iOS -> Runtime;
  React Native, Flutter... -> Framework) và không có category Package (mục
  Package thuộc Library; tệp khai báo thuộc Tooling).
- kind = node là loại gì: item (thư mục / mục cấp 1), concept (trang giải
  thích), function (hàm, method, lệnh), type (kiểu, lớp), element (thuộc
  tính, thẻ, sự kiện, directive). Chỉ item có vai trò trong mã: liệt kê node
  gốc qua liên kết và không bị đòi ví dụ.
- Thư mục lấy category của thứ nó chứa. Hàm / kiểu trong cây ngôn ngữ ->
  Module; dưới node gốc thư viện / framework / công cụ -> category của node
  gốc; dưới HTML / CSS -> Web; dưới SQL -> Database. Concept là mặc định.
- Chạy lại: node server/simplify-taxonomy.mjs (DRY=1 để đếm trước).


5. NỘI DUNG MỘT NODE
--------------------
Node lá: mô tả 1-2 câu -> code -> "## Kết quả" -> (tham số / giá trị) ->
"## Lưu ý". Cần: description EN (>= 12 từ), >= 1 alias, mô tả tiếng Việt.

- MỌI ví dụ code phải có "## Kết quả" ngay sau, nêu cụ thể chạy xong ra gì
  (hàm: giá trị trả về, output; thẻ / thuộc tính HTML: trình duyệt hiện gì;
  CSS: phần tử trông ra sao; CLI: output, file tạo ra). Mỗi giá trị / biến
  thể có kết quả riêng. Kết quả là chữ thuần, không ảnh.
- HTML / CSS có hiển thị: đầu "## Kết quả" có khối ```preview (HTML kèm
  <style>), tự đủ, không file ảnh ngoài (dùng data: SVG).
- Dòng code <= 110 ký tự. Kết quả của ví dụ chạy được là output THẬT do
  server/run-example.mjs chạy; ví dụ DOM / Node I/O / framework (norun) thì
  viết tay và rà lại. Output không được phụ thuộc hệ điều hành (dùng
  path.posix).
- Khối code trong @RESULT chạy trong vm: không dùng import, dùng
  require('node:...').

VÍ DỤ LẤY TRONG MỘT NGÔI TRƯỜNG
- Ví dụ code của ngôn ngữ lập trình dùng MỘT bối cảnh chung bao quát: ngôi
  trường. Đối tượng quen thuộc, dễ hình dung, đủ đa dạng để minh họa mọi
  khái niệm, và người đọc đi từ ngôn ngữ này sang ngôn ngữ khác vẫn gặp
  lại cùng một thế giới.
- Nhân vật và vật thể gợi ý: học sinh (student, name, age, score), giáo
  viên (teacher, subject), lớp học (class, danh sách học sinh, sĩ số), môn
  học (subject, credit), điểm số (grade, mark), bảng điểm (report card),
  thời khóa biểu (schedule), điểm danh (attendance), thư viện (book,
  borrow), học phí (fee), kỳ thi (exam).
- Chọn đúng đối tượng cho từng khái niệm: biến và kiểu (tên, tuổi, điểm),
  mảng / list (danh sách học sinh), map / dict (mã học sinh -> học sinh),
  set (các môn đã đăng ký, không trùng), class (Student, Teacher), kế thừa
  (Person -> Student / Teacher), interface / trait (Gradable), vòng lặp
  (duyệt lớp, tính điểm trung bình), điều kiện (xếp loại giỏi / khá / yếu),
  hàm (tính điểm trung bình), lỗi (điểm ngoài 0-10, học sinh không tồn
  tại), bất đồng bộ (tải bảng điểm), file / JSON (lưu danh sách lớp).
- Tên biến và hàm viết bằng tiếng Anh theo quy ước của ngôn ngữ (student,
  averageScore); dữ liệu mẫu có thể là tên người Việt ("An", "Bình").
- Chỉ áp dụng cho ví dụ chung của ngôn ngữ. Ví dụ buộc phải theo bản chất
  công cụ thì giữ nguyên: thẻ HTML, thuộc tính CSS, lệnh CLI, API của một
  thư viện / framework (Axios gọi URL, React render component...) - nhưng
  dữ liệu bên trong vẫn nên lấy từ trường học khi được.
- Một ví dụ một ý: không nhồi nhiều khái niệm; giữ ngắn (xem giới hạn 110
  ký tự mỗi dòng).


6. QUY TRÌNH LÀM MỘT NGÔN NGỮ
-----------------------------
Làm xong hẳn một ngôn ngữ (mọi mục + mọi node gốc hệ sinh thái của nó) rồi
mới sang ngôn ngữ khác. Số node là mức sàn, không phải trần.

Nguồn chính là server/data.db. Thư mục content/ chỉ tạo khi cần viết đợt mới
(md đã nhập xong thì xóa, không giữ). Viết content/<ngôn ngữ>/NN-ten.md, mỗi node
một khối:
  @@ NODE
  parent: <title | #id | ->      ("-" = node gốc)
  title: ...   kind: ...   category: ...   language: ...
  importance: 1-10   aliases: a; b   related: tên khác; ...   desc: EN
  retitle: Tên mới   (đi với "title: #id" để đổi tên, alias giữ tên cũ)
  replaces: ...      (xóa node cũ thay thế)
  ---
  Đoạn mô tả -> khối ```js (thêm `norun` nếu không chạy được) -> dòng
  @RESULT (chạy code, ghi "## Kết quả" bằng output thật) -> "## Lưu ý".

Lệnh:
  node server/import-md.mjs --dry content/javascript/NN-ten.md   kiểm tra
  node server/import-md.mjs content/javascript/NN-ten.md         ghi vào DB
  node server/check.mjs <Ngôn ngữ> --roots [--all]               kiểm tra chất lượng
  npm run export-data                                            ra public/data.json
  node server/merge-nodes.mjs (hàm mergeNode)                    gộp node trùng

- Importer chạy lại không hại (tìm node theo title). Nó nuốt lỗi: thiếu dòng
  tổng kết "tạo ..., cập nhật ..." nghĩa là có exception. kind phải thuộc
  bảng kinds (concept, item, function, type, element). Title trùng node của
  ngôn ngữ KHÁC bị thêm đuôi " (Ngôn ngữ)": kiểm tra trước (Zod đã ở
  TypeScript).
- Các file md cũ (01-25 của JavaScript) lệch so với DB sau nhiều lần đổi
  tên; không chạy lại hàng loạt.

XONG MỘT NGÔN NGỮ KHI: check.mjs <Ngôn ngữ> --roots báo SẠCH (có Kết quả,
mô tả EN, alias, không node rỗng, không dòng code dài, không emoji, không
tiêu đề trùng); đủ hệ sinh thái cơ bản; đã xem trên trình duyệt; đã commit.

Trạng thái: JavaScript SẠCH (khoảng 980 node gồm node gốc hệ sinh thái).
Các ngôn ngữ khác mới ở mức sàn, còn nhiều tiêu đề gộp (Python ~100,
PHP ~80, Kotlin / C# / Rust / Go ~75, HTML ~155) và chưa SẠCH. Thứ tự làm
tiếp: Python, TypeScript, Java, C#, Go, Rust, Kotlin, Swift, PHP, C++, C,
SQL, Ruby, Dart, R, Scala, Lua, Elixir, Haskell, Zig.


7. WEB ADMIN
------------
npm run dev rồi mở http://localhost:5199/admin (chỉ ở dev server). Mã:
admin/ (giao diện) + server/admin.mjs (API, gắn vào Vite). Thêm / sửa / xóa
node ở mọi cấp, nội dung, alias, quan hệ (hai chiều), thứ tự, di chuyển,
quản lý category / kind. Lần ghi đầu mỗi phiên tự sao lưu data.db vào
server/backups/ (đã gitignore). Bấm "Xuất data.json" hoặc npm run
export-data để app thấy thay đổi.
