VIỆC TIẾP THEO (theo thứ tự)
----------------------------
1. ĐÀO SÂU TỪNG NGÔN NGỮ TỪ GỐC ĐẾN NGỌN
   Làm xong hẳn một ngôn ngữ (mọi mục + mọi node gốc hệ sinh thái của nó)
   rồi mới sang ngôn ngữ khác. Chỉ tiêu là MỨC SÀN, không phải trần: ngôn
   ngữ nhiều chi tiết / module / framework thì nhiều node là bình thường.
   - HTML: mỗi thẻ có nhánh con cho TỪNG thuộc tính thẻ đó dùng được
     (a[href], a[target], img[srcset], input[min], form[method], video[poster],
     iframe[sandbox]...); thuộc tính toàn cục ([id], [hidden], [tabindex],
     [contenteditable], [popover]...); mọi input type; các thẻ còn thiếu
     (head / body, link, script, style, figure, time, abbr, sub / sup,
     dl, option / optgroup, thead / tbody, progress, meter, template...).
   - CSS: mỗi thuộc tính có node con cho từng giá trị / biến thể (display:
     none / block / inline-block, background-size: cover, transform:
     rotate(), justify-content: space-between, overflow: hidden,
     filter: blur()...); đủ pseudo-class, pseudo-element, đơn vị, hàm màu;
     các thuộc tính còn thiếu (color, cursor, visibility, pointer-events,
     clip-path, backdrop-filter, scroll-snap, vertical-align...).
     Thuộc tính gộp (shorthand) phải phân nhánh ra từng thuộc tính con,
     mỗi con một node có Kết quả: padding -> padding-top / -right /
     -bottom / -left (+ padding-inline / padding-block); margin, border
     (-width / -style / -color, từng cạnh), border-radius (từng góc),
     background (-color / -image / -size / -position / -repeat...), font
     (-family / -size / -weight / -style...), flex (-grow / -shrink /
     -basis), grid-template, grid-area, inset, overflow (-x / -y),
     transition (-property / -duration / -timing-function / -delay),
     animation (-name / -duration / -iteration-count / -direction...),
     outline, list-style, text-decoration, columns, gap (row / column).
   - Ngôn ngữ lập trình (càng chi tiết càng tốt): mỗi kiểu có ĐỦ method
     hay dùng; mỗi module thư viện chuẩn có các hàm / lớp chính; từ khóa, toán tử, cú pháp đặc biệt
     mỗi cái một node; framework / thư viện có đủ API chính (hook,
     decorator, lệnh CLI, cấu hình).
   Thứ tự: HTML, CSS, JavaScript, Python, TypeScript, Java, C#, Go, Rust,

ĐỊNH DẠNG CHUẨN (kiểm tra bằng audit.mjs)
-----------------------------------------
- Không giới hạn số con (scene và đường nối không giới hạn). Chỉ tạo item
  khi đó là phân loại thật (như cách MDN / tài liệu chính thức chia:
  Tags -> Inline text tags, Units / Colors, At-rules), KHÔNG gom chỉ để
  giảm số con.
- Data type: con là KIỂU (Basic types, String, List / Array, Map / Dict /
  Set, Option, enum...); method là node con của kiểu (mỗi kiểu chính
  >= 3). Không có node "X methods" đứng riêng.
- Control flow: đúng 2 con Condition và Loop; mỗi biến thể một node.
- Standard library: con là module hoặc nhóm module theo lĩnh vực; hàm /
  lớp là con của module. Không hàm lẻ, không nhóm "Other utilities".
- Thư viện / framework / công cụ bên thứ ba là NODE GỐC có @LANGUAGE, mục
  chỉ liên kết tới; công cụ chính thức (pip, go test...) là node thường.


QUY TẮC NỘI DUNG
----------------
- Node lá: mô tả 1-2 câu -> code -> ## Kết quả -> (tham số / giá trị)
  -> lưu ý.
- BẮT BUỘC: mọi ví dụ code phải có mục "## Kết quả" ngay sau code, cho
  thấy chạy xong thì ra gì và func / method / thuộc tính đó làm được gì:
  - Hàm / method: giá trị trả về, output in ra, biến bị đổi ra sao
    (ghi cụ thể: [1, 2, 3].map(x => x * 2) -> [2, 4, 6]).
  - Thẻ / thuộc tính HTML: trình duyệt hiện gì, hành vi gì (bấm thì mở
    tab mới, ô báo lỗi "Vui lòng nhập email", ảnh chỉ tải khi cuộn tới...).
  - Thuộc tính / giá trị CSS: phần tử trông / nằm ra sao sau khi áp.
  - Lệnh CLI / công cụ: output trên terminal, file được tạo.
  - Mỗi giá trị / biến thể trong ví dụ đều có kết quả riêng, không gộp
    chung "hiện đúng".
  Kết quả là chữ thuần (khối ``` hoặc gạch đầu dòng), không dùng ảnh.
  Mỗi dòng kết quả nêu rõ thẻ / thuộc tính / selector nào tạo ra nó
  (<h1> -> 32px...), không chỉ mô tả chung "to nhất", "đậm".
- HTML / CSS có hiển thị: đầu mục "## Kết quả" có khối ```preview (HTML,
  kèm <style> nếu là CSS) — app chạy nó trong khung trình duyệt thật
  (FocusContent.jsx), nên thấy đúng cỡ chữ, màu, bố cục. Ví dụ phải tự
  đủ (không file ảnh ngoài; dùng data: SVG). Form khi gửi / link khi bấm
  hiện dữ liệu thay vì chuyển trang. Thêm bằng add-preview.mjs.
- Tên: method có tiền tố người nhận (arr.map(), s.split()); hàm tĩnh giữ
  tên lớp / module (Object.keys(), re.search()); thuộc tính HTML dạng
  a[href]; trùng tên thì thêm ngoặc ("Loop (Go)", "Controller (Laravel)").
- Tiêu đề tiếng Anh, duy nhất toàn DB (không phân biệt hoa thường), không
  dấu phẩy; tên tiếng Việt và tên ngắn làm alias.
- Chỉ dùng ký tự có trong font Square-VN (không emoji, không tab).
